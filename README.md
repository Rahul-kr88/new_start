# 🍬 Sweet Shop Management System

A full-stack web application designed to simplify sweet shop operations through a user-friendly interface and backend application.

## 📌 Project Overview

The Sweet Shop Management System is a web-based application developed to provide a digital platform for managing sweet shop activities. It follows a frontend-backend architecture, with separate folders for the client-side application and server-side logic.

## 🛠️ Technology Stack

- **Frontend:** React.js
- **Backend:** Node.js
- **Backend Framework:** Express.js
- **Database:** MongoDB
- **Programming Language:** JavaScript
- **Version Control:** Git & GitHub

## 📂 Project Structure

```text
new_start/
│
├── frontend/
│   └── Frontend application
│
├── server/
│   └── Backend application
│
└── README.md
```

## ✨ Key Areas

- **Frontend Development:** Building an interactive user interface using React.js.
- **Backend Development:** Implementing server-side functionality using Node.js and Express.js.
- **Database Management:** Using MongoDB for data storage and management.
- **API Integration:** Connecting frontend and backend components.
- **Full-Stack Development:** Understanding the complete flow of a web application.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Rahul-kr88/new_start.git
```

### 2. Navigate to the Project Directory

```bash
cd new_start
```

### 3. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 4. Install Backend Dependencies

```bash
cd ../server
npm install
```

### 5. Configure Environment Variables

Create a `.env` file inside the server directory and configure the required environment variables according to your application setup.

### 6. Run the Application

Start the frontend and backend using the scripts configured in their respective `package.json` files.
